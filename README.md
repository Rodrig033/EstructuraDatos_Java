# Estructura de datos 🧑🏽‍💻 - Java
Algortimos de Búsqueda, Ordenamiento y Recursividad.
# Descripción Unidad 2  📄
En este repositorio almacenaré los algoritmos que se desarrollen durante las clases de **Estructura de datos**, en la cuál estaremos abordando algoritmos de **búsqueda (BinarySearch, LinearSearch),
 ordenamiento (QuickSort, MergeSort, InsertionSort) y recursividad (Fibonacci, Hanoi, Decision trees)**. 

## 🧰  Requisitos
- **Java JDK 17** o superior
- **Python 3.10** o superior
- **IntelliJ IDEA CE** o Visual Studio
- **Git** instalado para clonar el repositorio

## Instalación ⚙️
1. Clonar el repositorio:
```bash
git clone https://github.com/Rodrigo033/EstructuraDatos_Java.git
```
2. Abre la carpeta del proyecto en IntelliJ IDEA.
3. Solo si es necesario configura el SDK.
4. Ejecuta el archivo main desde la carpeta src/.
5. Ejecuta los programas de la carpeta correspondiente a la unidad 2:
 - src/unidad2 -> Algoritmos recursivos, ordenamiento y búsqueda
